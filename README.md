# Toothpick Challenge — Interactive Companion

An interactive companion to the **Toothpick Challenge** activity for BIOL 200. Students break toothpicks with each hand, time their trials, and use this page to calculate — and actually *see* — standard deviation, standard error, and confidence intervals, instead of just plugging numbers into a formula.

## For students

1. Open the live page (link above).
2. Work through the numbered sections in order (① through ⑥) — each one builds on the last.
3. Use your own group's toothpick-breaking times in Part 1; everything below updates from those numbers.
4. If you get stuck on Part 3, use the "Show worked answer" button under each hand's calculation.

## For teachers

- **Pacing:** Sections ① and ② (the distribution curve and the simulation) work best projected and explored as a class before students move into their own data in ③–⑥.
- **"Show statistics terms (t, z, df)"** is off by default, so the page stays intuitive for students seeing this for the first time. Turn it on yourself when you're ready to introduce the formal vocabulary.
- **"Clear all trial data"** empties both hands' inputs. **"Load sample data"** restores the built-in demo numbers — handy if a group wants to reset without losing the worked example.
- Everything recalculates live from whatever is in Part 1, including the critical-value table highlight, so there's nothing to "run" or refresh.

## Updating the page

1. Open this repository on GitHub.
2. Click `index.html` → the pencil (edit) icon.
3. Make your changes and commit.
4. GitHub Pages rebuilds automatically — the live link updates within about a minute.
